# vidya

> _vidya_（विद्या）：知识，洞见，第一性的看见。

这是一份个人的认知工程项目。目的不是收藏文章，而是从极少数极聪明的人花了大量时间想清楚、再用力压缩出来的文本里，提取第一性的认知，再把这些认知重新打包成可执行的 skill，用来辅助我做事和思考。

## 思路

- **canon** 是水源。CS 领域奠基性的论文、演讲、笔记——每一篇都是一次极致的压缩。直接读它们，比读 100 篇二手解读更高效。
- **skills** 是水管。把从 canon 里读出来的判断、动作、检查清单，重新组织成 Agent 可以调用的形式。一个 skill 通常背后站着一两篇文章，或一组互相印证的文章。
- **templates** 是模具。新 skill 从这里复制起手。

读 canon 不是为了博学，是为了让脑子里有一组可重用的概念动作（"这是 simple 还是 easy？"、"这是本质复杂度还是附属复杂度？"、"A 在 B 之前发生吗？"）。skill 则把这些动作固化成可重复执行的流程。

## 结构

```text
vidya/
├── canon/           # 经典文章中文版，每篇附一段独立判断
├── skills/          # 可复用的 Agent skills
│   └── <skill-name>/
│       ├── SKILL.md       # 单一事实来源
│       ├── references/
│       ├── scripts/
│       └── assets/
└── templates/
    └── skill/             # 新 skill 起手模板
```

## 规则

- 每个 skill 独立目录，以 `SKILL.md` 为单一事实来源。
- 不在核心仓库存放平台相关的元数据。
- canon 里每一篇都附一段独立判断——不是摘要，是"这篇值不值得反复回来翻、它独有的贡献是什么、哪里高估了"。
