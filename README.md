# vidya

可复用的 Agent skills，以及各领域奠基性文章的中文版。

## 结构

```text
vidya/
├── skills/          # 可复用的 Agent skills
│   └── <skill-name>/
│       ├── SKILL.md
│       ├── references/
│       ├── scripts/
│       └── assets/
└── canon/           # 各领域经典文章中文版（持续收录）
```

## 规则

- 每个 skill 放在独立目录下
- 以 `SKILL.md` 为单一事实来源
- 不在核心仓库中存放平台相关的元数据
