# vidyā · विद्या

直接看见。

## 这是什么

有些人花了几十年，把自己的经验、思考，和消化过的别人的工作，沉淀进了文字里——这是世上最稀缺的认知资产。

vidyā 是把这些东西一份份亲自读完、亲自理解，并把理解沉淀下来的项目。

## 关于这个名字

vidyā（विद्या）来自梵语。词根 √vid 同时意味着"看见"和"知道"——这两件事，在这个词里是同一件事。

在印度哲学传统里，vidyā 指的不是关于某事的信息，而是一种会改变知者本身的看见。它的反面 avidyā 不是"无知"——是结构性的看不清。明明看着，却把绳子看成蛇，把自己看成与世界分离的、独立的、永远不会终结的什么东西。

## 原则

要读的文字背后是一个具体的人——和我一样有限，有和我一样会死的肉身。

理解是发生在两个人类之间的碰撞——我读到某句话时，忽然识别出一种自己一直没说出口的经验；体会到一种说不清的感觉被另一个人讲了出来；或者一个我反复想不通的东西，在他写下的那段文字里变清楚了。没有肉身的 AI 不懂这些。

所以这里有一条不能让步的边界：

* 文字得是人类写的，理解得是我亲自做的。
* AI 只是辅助，不容置喙。
* 用我理解过的东西去指导 AI，把它实现成可用的形态。

目前选择的形态是 skill。skill 只是当下方便的一种形态，不是唯一的形态。

## 结构


## canon

收录人类自己写下的东西。形式不限——书、文章、信件、日记、演讲实录、对话、笔记——重要的是有一个具体的人在里面，他自己活过、想过、付出过代价。

宁缺毋滥。今天能读到的东西太多了，绝大部分是悬浮的——为了发表而写的，为了流量而写的，为了完成任务而写的，或者干脆不是人写的。canon 只收沉淀了足够多东西的内容：作者在它上面花过很长时间，消化过别人的工作，付出过代价，写的时候没有在表演。

这一类东西是稀缺的。所以这里宁可慢，宁可少，宁可空。

做分类、索引、关联，会简单介绍作者——但不替读者消化。那一步必须每个人自己走。

## skills

skill 是把一件我已经理解过的事，固定成 AI 能稳定执行的形态。

顺序不可逆：先理解，再 skill。没有理解就生成的 skill，是 avidyā 的化身——它能运行，但不知道自己在做什么。
